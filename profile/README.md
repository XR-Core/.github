XR Core is a RedM framework, simple to build on.

Characters to telegrams, built together so the server feels like one place: characters, appearance, clothing, barbers, banking, shops, stables, telegrams, herbalism, medical, the HUD, animations, weather, world density and staff tools. Every menu, progress bar and dialogue is drawn by one library in one look.

Underneath, the exports use the same verbs everywhere (get, add, remove, set), and every write returns `true`, or `false` and a reason. It's built on ox_lib, oxmysql and ox_inventory.

**Pre-release (0.0.x).** APIs may change before 1.0. The code isn't public yet.
